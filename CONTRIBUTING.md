# Contributing

Contributions are welcome if they fit the project direction.

By submitting a contribution, you agree that your contribution may be used,
modified, redistributed, and relicensed as part of Faker.cpp under the
project's current Apache-2.0 license or any future license chosen by the
project maintainer.

Only submit work that you have the right to contribute. Do not submit code,
data, documentation, or other material copied from another project unless its
license allows that use and the source is clearly noted.

Before opening a pull request:

- build the project with CMake
- run the test suite
- keep changes focused on one purpose
- update docs when public behavior changes
